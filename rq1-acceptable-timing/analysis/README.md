# Acceptability analysis

`plot_session_curve.py` creates the pooled acceptance curve; `plot_session_heatmap.py` shows ratings by transition and offset. `mark_check.py` and `scene_dependence.py` are exploratory diagnostics.

## Required context

Requires NumPy, SciPy, Matplotlib and librosa, plus authorised sessions and audio inputs. Original session filenames remain as defaults, but the files are not shipped. Figures go to the RQ1 figures directory or the root results/figures directory, as specified in each script.
