# RQ1: Acceptable timing

How do the size and direction of a scene cut's firing offset affect its acceptability? Does that relationship differ between transitions, according to the director who made the film?

## Contents

- [study-app/](study-app/README.md): Browser application for presenting offset cuts and collecting ratings.
- [analysis/](analysis/README.md): Pooled acceptance curve, per-target ratings and exploratory diagnostics.

## Inputs

Your own authorised conductor video, film clips and transition configuration. The original response sessions are excluded.

## Outputs

The application exports ratings. Analysis scripts create figures and summaries; exact thesis results require the original authorised sessions.

## Running and limitations

Start with study-app/README.md. The app and analysis use different runtime environments. Each cell in the heatmap shows an individual rating, so it cannot establish a consistent preference on its own.

See [setup instructions](../RUNNING.md), [excluded inputs](../INPUTS.md) and [shared dependencies](../shared/README.md).
