# Cue-correction experiments

`run_all_follower_cue_corrections.py` is the final three-method entry point. `visual_all_cue_resets.py` and `visual_paired_cue_resets.py` retain the original protocol and reusable functions.

## Required context

The three-method runner imports RQ3 decoder helpers and RQ5 scoring. It requires the saved detector, landmark, alignment, trace and feature-cache inputs listed in INPUTS.md.
